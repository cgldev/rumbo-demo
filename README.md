# Rumbo — landing page de agencia de viajes

Sitio demo de una agencia de viajes ficticia, creado para practicar la maquetación de una landing page responsive y la composición de secciones comerciales.

## Secciones

- Presentación principal con llamada a la acción.
- Locaciones y beneficios.
- Tarjetas de servicios.
- Formulario visual de contacto.
- Navegación por anclas entre secciones.

## Tecnologías

- HTML5
- CSS
- JavaScript para la interfaz y recursos del sitio

## Ejecutar localmente

Cloná el repositorio y abrí `index.html` en tu navegador:

```bash
git clone https://github.com/cgldev/rumbo-demo.git
cd rumbo-demo
```

No requiere instalación de dependencias para abrir la página estática.

## Alcance

Es un sitio demostrativo de frontend. El formulario y las llamadas a la acción son elementos visuales; no realizan reservas ni envían mensajes a un backend.
